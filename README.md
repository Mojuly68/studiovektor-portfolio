## About these projects

These are unsolicited **concept redesigns** created by studiovektor for portfolio purposes. They are not affiliated with or endorsed by the companies shown, and every page carries a visible "Concept redesign" label. Company names, logos and photography belong to their respective owners.

Each site is plain static HTML, CSS and JavaScript. The studiovektor and CGM pages run on a bundled component runtime (`support.js`).
